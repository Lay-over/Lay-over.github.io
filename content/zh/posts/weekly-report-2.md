## 关于 Python 和 C 的一点对比

Python 我现在看到了变量、数据类型和输入输出这一块。因为同时在写 C，两边一对照，很多地方还挺有意思的。

C 里用变量得先声明类型，比如 `int a = 10;`，写死了是整数；Python 直接 `a = 10` 就行，而且同一个变量后面还能改成别的类型。一开始我还不太习惯，后来想明白了，C 这样其实是对应内存里怎么存数据，Python 是把这些底层的东西帮我处理掉了。

输入输出差别也挺大。C 用 scanf、printf，要自己写 %d、%f 这些格式符，还得加 &；Python 一个 input() 就收进来了，不过它收进来的默认都是字符串，想当数字用得自己 int() 转一下。这点我还踩过坑，直接拿 input 的结果去加减，结果报错了。

C 最近在讲数组和函数，我就顺手看了下 Python 的列表和 def。感觉核心思路是一样的，都是把一堆数据放一起、把一段逻辑包起来重复用，只是写法不一样。C 那边数组长度固定、类型也得一致，Python 列表就随便多了，能随时加东西。

## 用 Python 把网安的东西自己写一遍

课堂上更多是用现成工具，我想试试自己写代码是不是真能实现。

第一个写的是凯撒密码。原理其实不复杂，就是把字母按固定位数往后挪。我写了个函数做加密，然后又用循环把 0 到 25 每种移位都试了一遍，算是暴力破解。自己写完才理解为什么说这种密码不安全，密钥就 26 种可能，电脑一下就穷举完了。中间处理字母的时候还遇到越界的问题，挪到 z 之后就乱了，后来用 % 26 取余让它绕回 a 才解决。

然后是哈希。我用 Python 的 hashlib 算了一下 SHA-256，特意把 hello 改成 hellp 对比，结果两个十六进制串完全不一样，差一个字母就差这么多，这就是课上说的雪崩效应，自己跑一遍看结果比听课直观多了。也顺便理解了哈希是没法反推出原文的。

还有信息隐藏那个实验，课上是用 copy /B 把文本拼到图片后面。我在课外用 Python 以二进制方式打开文件，发现本质就是把图片和文本的字节读出来拼在一起再写回去，所以新文件大小正好是两者之和。搞懂原理之后更确定了，这只是把东西藏起来，根本不是加密，真要保密还是得加密。
