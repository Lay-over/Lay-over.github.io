## 模运算

模运算就是取余，a mod n 表示 a 除以 n 的余数，Python 里写 a % n。它把任意整数映射到 0 到 n-1 的范围内，是后面绝大多数密码算法的基础。

同余：如果 a 和 b 除以 n 的余数相同，就记作 a ≡ b (mod n)。例如 17 和 3 在模 7 下同余，因为都余 3。

注意点：负数取模在不同语言里结果可能不同。Python 中 -7 % 5 = 3，而 C 语言中结果是 -2。

## 异或 XOR

异或的规则：两个位相同得 0，不同得 1。

性质：

- 任何数与 0 异或等于它本身
- 任何数与它本身异或等于 0
- 满足交换律和结合律

推论：A ^ B ^ B = A。流密码正是利用这个性质——明文与密钥异或得到密文，密文再与密钥异或一次就还原为明文，加解密使用同一操作。

## 最大公约数与欧几里得算法

欧几里得算法（辗转相除法）用于求最大公约数，核心递推式：gcd(a, b) = gcd(b, a % b)，直到余数为 0。

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```

该算法是后续计算模逆元、理解 RSA 的基础。

## 凯撒密码

把字母统一向后移动固定位数，例如移 3 位：A→D、B→E、Z→C。密钥就是位移量，只有 26 种可能，因此可暴力破解。

实现时用 % 26 处理字母越界，让字母绕回开头：

```python
def caesar(text, shift):
    result = ""
    for ch in text:
        if 'a' <= ch <= 'z':
            result += chr((ord(ch) - ord('a') + shift) % 26 + ord('a'))
        elif 'A' <= ch <= 'Z':
            result += chr((ord(ch) - ord('A') + shift) % 26 + ord('A'))
        else:
            result += ch
    return result
```

暴力破解即遍历 0 到 25 的所有位移，从输出中找出可读的明文。

## 替换密码与频率分析

替换密码给每个字母随机分配一个对应字母，密钥空间为 26!，暴力破解不可行，改用频率分析。

频率分析利用字母出现频率的规律：英文中 e 出现最多，t、a 也靠前。当密文足够长时，统计各字母出现次数并对照频率表，即可推断对应关系。

## 维吉尼亚密码

凯撒密码的升级版，用一串密钥循环移位，不同位置的位移量不同，因此简单的频率分析失效。

破解思路：先推测密钥长度，再按长度分组，每组单独做频率分析。
